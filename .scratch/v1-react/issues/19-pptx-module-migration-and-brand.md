# 19: PPTX full module migration and naming

**What to build:** Migrate every module in `public/lectern/js/` into `pptx/`; implement UI and interaction modules as typed React components/hooks, keep presentation and OOXML algorithms as typed non-UI services, and remove runtime dependence on the legacy Lectern directory.

**Blocked by:** 00: Direct editor-engine mount foundation; 01: Vite workspace and editor package contract; 02: Shared UI interface foundation; 16: Shared UI module migration to React.

**Status:** in-progress

**Progress:** The slide show registers an editor-mount cleanup and exits without user prompts if the React editor is disposed during playback. Capitalized Lectern product references across `public/lectern/js/` are now PPTX, while the one-document desktop title/edition-name compatibility and lowercase host/routes remain. The React package now owns speaker notes, the normal slide-thumbnail rail, Outline, Slide Sorter, Notes Page, Print Preview controls, slide-show navigation/menu triggers, numeric Go to Slide prompt, black/white screen and end-of-show overlays, Rehearse controls/timer display, Slides/Outline pane chrome, task-pane navigation chrome, and the Getting Started/New Presentation/searchable Help/Clip Art/Slide Design/Color Schemes/Animation Schemes/Slide Layout/Slide Transition/Custom Animation/Clipboard pane bodies, forwarding edits, selection, reorder, preview, print configuration, creation, search, insertion, design/palette/animation/layout/transition application and import, custom-effect editing, clipboard history/paste, and pane-history operations into engine adapters. Slide-show stage rendering, transition/ink/timing algorithms, slide artwork, other task-pane content, dialogs, ribbon, and most other UI still run from classic `public/lectern/js/`. Full React module migration remains outstanding.

## Acceptance

- [ ] Every source module under `public/lectern/js/` has an accounted-for PPTX package implementation or an explicit shared-service destination.
- [ ] Slide canvas, text editing, panes, dialogs, commands, menus, ribbon, slideshow controls, and interaction handlers are React-owned.
- [ ] PPTX package, standalone entry, and suite run without loading `public/lectern/` or using an iframe.
- [ ] Web-owned Lectern names are migrated to PPTX in identifiers, storage keys, custom MIME types, visible strings, docs, tests, paths, and generated outputs.
- [ ] PPTX/PresentationML technical identifiers and Microsoft PowerPoint interoperability terminology remain standards-correct.
- [ ] Existing PPTX visual, interaction, local/remote file, and OOXML compatibility suites pass.
